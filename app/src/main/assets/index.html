Shortcut to Size

Everything is saved on this phone as you type — no account, no signal needed. Copy summary prints every set you’ve logged, earlier blocks included — paste it into a chat when you want the block reviewed. Copy backup copies the raw data, which is what Restore backup reads. Load program swaps in a whole new training block from pasted text, keeping your history — no app update needed.
Reps fall and sets rise across each four-week phase: 12–15, 9–11, 6–8, then heavy. Weeks 5–8 repeat it with rotated accessories. Capped lifts show their RPE ceiling instead of a technique and never get one.
